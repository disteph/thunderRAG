1. Email Ingestion

Two paths: Sync (POST /ingest) processes a single email inline and returns the result. Async batch (POST /ingest/batch) queues emails into ingest_queue and returns immediately — the daemon's Phase −1 processes them. The add-on uses the async path for multi-select and filter-action ingestion.

2. Background Daemon

Runs continuously in the background. Phase −1 (async ingestion) runs at all times. Phases 0–2 defer whenever user queries or interactive requests are active (high_priority_count > 0). Processes one item per loop iteration, then checks priority again.

Dequeue a raw email from ingest_queue, run the full ingestion pipeline (parse → compress → embed → store → enqueue triage)
ingest_queue table

4. Task Chat (draft-then-refine)

Per-task conversation via /task/chat. The daemon produces a first draft; the LLM then asks targeted questions to refine it. Supports structured markers for side effects and [RETRIEVE] for on-demand archive search.

task_interview_system task_interview_user

Prior resolutions: notes & drafts from similar resolved tasks, for continuity.
On completion calls: ephemeral [retrieved] emails are injected into the context too.
Generate response
